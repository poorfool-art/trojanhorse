# Инструкция по установке

## Шаг 0. Установи Python (если ещё нет)
Скачай с https://www.python.org/downloads/ (при установке отметь галочку "Add Python to PATH")

## Шаг 1. Настрой encrypt_program.py
Открой файл в блокноте и поменяй:
- `SOURCE_EXE` — путь к твоей настоящей программе
- `OUTPUT_FILE` — куда сохранить зашифрованный файл (можно оставить как есть, но поменяй "ТвойПользователь" на своё имя пользователя Windows)
- `PASSWORD` — придумай пароль

## Шаг 2. Запусти шифрование
Открой командную строку (cmd) в папке с файлами и выполни:
```
pip install cryptography
python encrypt_program.py
```
После этого удали исходный незашифрованный exe-файл (или перенеси на флешку).

## Шаг 3. Настрой launcher.py
Открой файл, укажи:
- `ENCRYPTED_FILE` — тот же путь, что был в `OUTPUT_FILE` на шаге 1
- `SALT` — оставь как есть, либо поменяй (главное чтобы совпадало с encrypt_program.py)
- `DECOY_PROGRAM_PATH` — что открывать при неверном пароле

## Шаг 4. Собери exe
Дважды кликни `build.bat` — он сам установит всё нужное и соберёт файл.
Готовый exe появится в папке `dist\launcher.exe`.

## Шаг 5. Финал
- Переименуй `dist\launcher.exe` во что угодно (например `game.exe`)
- Помести туда, где брат его увидит и запустит
- Убедись, что зашифрованный `.dat` файл на месте, а оригинальный exe удалён/спрятан
- Проверь сам, что при правильном пароле программа запускается, а при неправильном — заглушка

## Файлы в комплекте
- `encrypt_program.py` — шифрует оригинальную программу (запускается один раз)
- `launcher.py` — сам лаунчер с запросом пароля (из него собирается exe)
- `build.bat` — автоматическая сборка exe
